# Kanishka M – Portfolio Website

Built with HTML, CSS and JavaScript (no frameworks).

## Files
- `index.html` – page structure
- `style.css` – styling
- `script.js` – certificate filter, menu, animations, contact form
- `assets/Kanishka_M_Resume.pdf` – downloadable resume

## Run locally
Open `index.html` in a browser.

## Push to GitHub
```
git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/25bcs031-arch/portfolio.git
git push -u origin main
```
(Create an empty repository named `portfolio` on GitHub first.)

## Deploy (GitHub Pages)
1. Open the repository on GitHub, then Settings, then Pages.
2. Under Source choose "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
3. After a minute the site is live at https://25bcs031-arch.github.io/portfolio/
